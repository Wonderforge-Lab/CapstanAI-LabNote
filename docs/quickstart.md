# Quickstart

1. Create or identify a visitor/session ID.
2. Copy `templates/datadrop_packet.md`.
3. Fill in the packet header and task sections.
4. Register the packet in `registry/packet_registry.csv`.
5. Give the packet to the target assistant session.
6. Copy `templates/ai_response_packet.md` for the answer.
7. Register the response in `registry/response_registry.csv`.
8. Review the response before marking anything accepted.

Small files, clear labels, no mystery memory. That is the trick.
