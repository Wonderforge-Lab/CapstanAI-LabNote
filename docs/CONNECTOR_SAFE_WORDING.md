# Connector-Safe Wording

Repo-facing files should use clear technical wording.

Conversational metaphors are fine in chat, but repository files should avoid metaphor-heavy phrasing when it might be misread by connector safety filters.

Prefer:

- early-stage model
- small experimental model
- supervised guardrail stack
- local teacher model
- resident agent
- deterministic scaffold
- review layer
- safety wrapper

Avoid making repo files depend on ambiguous metaphorical vocabulary when formal wording will do.

This is not a ban on project language. It is a compatibility rule for files written through connectors.
