# Storage Policy

Use this repository for small text artifacts:

- packets,
- responses,
- templates,
- registries,
- visitor notes,
- review notes,
- signoffs,
- protocol docs.

Do not commit large raw dumps, long private transcripts, PDFs, images beyond project assets, generated bundles, logs, or bulky exports.

Put heavy or private material in external storage controlled by the operator. Link to it by stable title, path, or URL when a packet needs context. The repository is the ledger, not the warehouse.
