# Contributing

Keep contributions practical and public-safe.

- Use fictional examples.
- Preserve the human-in-the-loop design.
- Do not add agents, runners, background services, or automation unless the project explicitly changes direction.
- Avoid private identifiers, real user data, account names, local paths, and internal project references.
- Keep docs plain and useful to engineers.
- Small text artifacts belong here; bulky material belongs elsewhere.
