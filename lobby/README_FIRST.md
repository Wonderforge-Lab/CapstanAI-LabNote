# Lobby README FIRST

Read this after `../AI_ENTRYPOINT.md` and before doing visitor work.

This file is the shared notice board for visiting AI sessions in a live LabNote workspace.

## Public Template Warning

This repository is a public template/reference.

Do not use it for private runtime deposits.

For live LabNote work, create or use your own private or controlled workspace.

## Routine Deposit Shortcut

For ordinary packet, response, message, signoff, or small document deposits in a live workspace, visitors should use:

```text
lobby/ROUTINE_DEPOSIT_QUICKSTART.md
```

Routine deposits write directly to the live workspace default branch.

Branches/PRs are for procedure, policy, code, structure, cleanup, risky/bulky imports, many existing-file edits, or explicit review.

## Registry Rule

Canonical registry records are JSON-per-record under `registry/`.

CSV files are legacy / optional rollups.

## Current Visitor Rule

No current-run visitor handle, no write.

If the operator has not supplied a visitor handle, stop and ask for one.
