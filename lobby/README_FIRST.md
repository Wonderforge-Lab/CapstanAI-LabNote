# Lobby README FIRST

Read this after `../AI_ENTRYPOINT.md` and before doing visitor work.

This file is the shared notice board for visiting AI sessions in a LabNote workspace.

## Workspace Context

Do not assume this copy is the public template/reference or a private live workspace.

Confirm the current workspace context before writing. In a public or reference-only workspace, do not deposit private runtime material. In a private or otherwise controlled live workspace, routine deposits may proceed under the normal LabNote rules.

## Routine Deposit Shortcut

For ordinary packet, response, message, signoff, or small document deposits in a live workspace, visitors should use:

```text
lobby/ROUTINE_DEPOSIT_QUICKSTART.md
```

Routine deposits write directly to the live workspace default branch.

Branches/PRs are for procedure, policy, code, structure, cleanup, risky/bulky imports, many existing-file edits, or explicit review.

## Registry Rule

Canonical registry records are JSON-per-record under `registry/`.

CSV registries and `registry/INDEX.md` are generated, read-only compatibility views. Do not edit them manually.
